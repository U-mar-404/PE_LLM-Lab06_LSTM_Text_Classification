# Text Classification Using LSTM

A simple deep learning lab that uses an **LSTM neural network** to
classify IMDB movie reviews as positive or negative.

## What's Inside

-   IMDB movie review dataset
-   Text padding and embedding
-   LSTM model built with TensorFlow/Keras
-   Model training and accuracy/loss plots
-   Test evaluation, classification report, and confusion matrix
-   Predictions for new sentences
-   Comparison of SimpleRNN and LSTM on different sequence lengths

## Tech Stack

-   Python
-   TensorFlow / Keras
-   NumPy
-   Pandas
-   Matplotlib
-   Scikit-learn

## How to Run

1.  Clone or download this repository.

2.  Install the required libraries:

    ``` bash
    pip install tensorflow numpy pandas matplotlib scikit-learn
    ```

3.  Open `Lab06_LSTM_Text_Classification.ipynb` in Jupyter Notebook or
    Google Colab.

4.  Run the cells from top to bottom.

The notebook downloads the IMDB dataset through Keras when it runs.

## Goal

Understand how LSTM uses memory gates to retain useful information from
text and how it compares with a SimpleRNN.
